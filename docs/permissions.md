# Permissions (สิทธิ์การใช้งาน)

การควบคุมสิทธิ์ (Role-based Access Control) จะทำงาน 2 ชั้น:
1. **Middleware**: ควบคุมการเข้าถึงหน้าเว็บ (UI Routes)
2. **Server Actions / API**: ควบคุมการแก้ไขข้อมูล

## ตารางสิทธิ์ตาม Route (UI)

| Route (Path) | บุคคลทั่วไป (Guest) | CUSTOMER | ADMIN | หมายเหตุ |
| :--- | :---: | :---: | :---: | :--- |
| `/` (หน้าแรก) | ✅ | ✅ | ✅ | |
| `/products/**` | ✅ | ✅ | ✅ | |
| `/cart` | ✅ | ✅ | ✅ | ตะกร้าเก็บใน localStorage/Cookie หรือ DB ก็ได้ |
| `/login`, `/register` | ✅ | ❌ | ❌ | ถ้าล็อกอินแล้วจะ redirect ไปหน้าแรก |
| `/checkout` | ❌ | ✅ | ✅ | บังคับล็อกอินก่อนชำระเงิน |
| `/account/**` | ❌ | ✅ | ✅ | ดูโปรไฟล์/ออเดอร์ของตัวเอง |
| `/admin/**` | ❌ | ❌ | ✅ | จัดการระบบ |

## ตารางสิทธิ์ระดับ Data / Action

| Action / Resource | CUSTOMER | ADMIN |
| :--- | :--- | :--- |
| **Product** | ดูเฉพาะ isActive=true | สร้าง, แก้ไข, ปิดการขาย (isActive=false) ทุกสินค้า |
| **Category** | ดูทั้งหมด | สร้าง, แก้ไข, ลบ |
| **Order** | สร้างออเดอร์ให้ตัวเอง, ดูออเดอร์ตัวเอง, ยกเลิกออเดอร์ตัวเอง(ถ้ารอชำระ) | ดูทุกออเดอร์, เปลี่ยนสถานะออเดอร์ (ตาม flow) |
| **Address** | จัดการที่อยู่ของตัวเอง | ดูที่อยู่ตามใบสั่งซื้อ |
| **User** | แก้ไขโปรไฟล์ตัวเอง | ดูข้อมูลผู้ใช้ทุกคน, ปรับ role |
